# 🥗 Calorie Calculator

## 👩‍💻 Author
Lakshmi

## 📌 Project Description

The Calorie Calculator is a beginner-friendly Python and Streamlit application that estimates a user's daily calorie requirement based on personal details and activity level.

The application provides a simple and attractive interface where users can enter their details and receive an estimated daily calorie requirement.

## ✨ Features

- 👤 Enter age
- ⚖️ Enter weight
- 📏 Enter height
- 🚻 Select gender
- 🏃 Select activity level
- 🧮 Calculate estimated calorie requirement
- 🔥 Display estimated daily calories
- 💡 Provide a simple interpretation of the result
- 📱 User-friendly Streamlit interface
- 🚫 No database used

## 🛠️ Technologies Used

- Python
- Streamlit

## 📊 Personal Details

The application accepts:

- Age
- Gender
- Weight in kilograms
- Height in centimeters

## 🏃 Activity Levels

The application provides the following activity levels:

1. Sedentary - little or no exercise
2. Lightly Active - exercise 1-3 days/week
3. Moderately Active - exercise 3-5 days/week
4. Very Active - exercise 6-7 days/week
5. Extra Active - very intense exercise

## 🧮 Calculation

The application first estimates BMR using the Mifflin-St Jeor equation.

The estimated daily calorie requirement is then calculated using the selected activity level.
